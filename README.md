# Hitachi-YOLO-Image
# Bird Biodiversity Monitoring: Object Detection (.ipynb)

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1bzym15FMbqbax_HDJ8UuNynsN6opTqZC?usp=sharing)

Collected and curated over 1,500 real-world bird images and video frames, performing dataset annotation using Label Studio for biodiversity monitoring. Trained and optimized CNN and YOLOv11 object detection models in this Jupyter Notebook (`.ipynb`), achieving 0.70 mAP through hyperparameter tuning, augmentation and iterative evaluation. Built preprocessing, inference and validation pipelines while documenting experiments for an ongoing computer vision research publication.
